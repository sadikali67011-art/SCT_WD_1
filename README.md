# SkillCraft Technology - Task 01

## Responsive Landing Page

This project is created as part of my **Web Development Internship at SkillCraft Technology**.

The objective of this task is to create an interactive and responsive landing page with a fixed navigation menu that changes its style when the user scrolls and when menu items are hovered.

## 🚀 Features

* Fixed navigation bar
* Navigation bar changes style on scroll
* Hover effects on navigation links
* Active navigation link based on current section
* Smooth scrolling
* Responsive design
* Mobile-friendly layout
* Interactive buttons
* Modern card-based sections
* Responsive hero section
* Clean footer section

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
